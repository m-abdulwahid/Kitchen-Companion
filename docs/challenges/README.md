# Sponsor challenge submissions

Kitchen Companion is submitting to the three challenges it can demonstrate in
the working product. Each document is written to be reusable as a Devpost
“How we used…” response and as a judge-facing demo guide.

| Challenge | Submission note | Core proof |
| --- | --- | --- |
| Huawei OMNI Live | [huawei-omni-live.md](huawei-omni-live.md) | A cook speaks naturally while the assistant hears, answers aloud, and checks a camera frame against the current recipe step. |
| Built on Backboard | [backboard.md](backboard.md) | An explicit allergy or cooking preference survives into a new recipe session without exposing a name or email. |
| Sentry | [sentry.md](sentry.md) | One camera-to-coaching interaction appears as a trace, with privacy-masked replay and backend profiling available for debugging. |

We are deliberately not submitting to Shopify, Baseten/Browserbase, or the
OpenAI API + Codex prize: those services are not part of the running product.
Codex was used to develop this repository, but that does not satisfy the
OpenAI API requirement on its own.
